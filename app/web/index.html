⚡ Direct QA Mode Active
Fast, Single-Turn Evidence Retrieval

Directly answers factual inquiries by querying your document repository simultaneously with semantic dense vector embeddings (ChromaDB) and lexical keyword search (SQLite BM25 FTS5). Fuses candidates via Reciprocal Rank Fusion (RRF, k=60) and Cohere Rerank v3 cross-encoders. Every response is strictly grounded in inspectable [S1]..[Sn] citations.

🔍 Hybrid Dual-Index ⚡ RRF Fusion (k=60) 🎯 Cohere Rerank 🏷️ Verifiable [S#] Citations 🌐 Academic Web Fallback
🤖 Autonomous Agent Mode Active
Multi-Tool Reasoning & Cross-Paper Analysis

Autonomous research agent powered by LlamaIndex and DeepSeek / Gemini. The agent analyzes the objective of your inquiry, selects specialized analytical tools, inspects raw document passages across your library, and synthesizes multi-step comparative investigations.

Specialized Agent Analytical Tools:
📊 Metrics Table Tabular Extraction

Mines performance statistics across papers and compiles a structured comparison table with models, accuracy %, datasets, and metrics.

⚖️ Compare Papers Comparative Contrast

Performs a rigorous side-by-side comparative analysis of algorithmic architectures, feature choices, and trade-offs.

📑 Summarize Paper Structured Synthesis

Produces a multi-section structured breakdown covering objective, architecture, dataset, and clinical/empirical results.

🔢 Quantitative Stats Numeric Extraction

Queries exact patient cohort sizes, class distributions, confidence intervals, and statistical metrics across the corpus.

🧠 Plan & Execute Mode Active
Hypothesis Decomposition & Meta-Synthesis

A dedicated planning agent decomposes complex, multi-part research inquiries into structured sub-hypotheses. Each sub-question is independently investigated and answered with cited evidence, followed by an executive meta-analysis.

1 Plan Decomposition: Breaks complex inquiry into targeted sub-questions
2 Parallel Evidence Gathering: Answers each sub-question with citations
3 Meta-Synthesis: Synthesizes sub-answers into an exhaustive report
4 Inspectable Steps: Review each sub-question in the response plan
